# DoneDay — Task Tracker

A simple website for managing daily tasks and tracking progress.

## Features
- Add and delete tasks
- Mark tasks as completed
- Search and filter tasks
- Save tasks in localStorage
- Light and dark mode

## Technologies
HTML, CSS, JavaScript, TypeScript, Vite.

## Run
```bash
npm install
npm run dev
```
